6. [Roadmap](plan/06-roadmap.md) — fases, versiones y criterios de salida.
7. [Calidad y harness](plan/07-calidad-harness.md) — cómo se verifica todo (agentes, contenido, pruebas, CI).
8. [Backlog](plan/backlog.md) — tareas ejecutables.

10. [ADR](decisiones/adr.md) — decisiones técnicas tomadas y por qué.

12. [Glosario](glosario.md) — vocabulario del dominio.
