# `mkdir`

## Para qué sirve

`mkdir` crea carpetas. Viene de *make directory*.

## Ejemplo

```
$ mkdir respaldo
$ mkdir -p respaldo/2026/octubre
```

## En este servidor

- `-p`: crea también las carpetas intermedias y no se queja si ya existen.

## En tu Linux real

Igual. Con `-v` te dice qué fue creando.
