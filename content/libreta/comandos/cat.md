# `cat`

## Para qué sirve

`cat` muestra todo lo que tiene un archivo de texto. Viene de *concatenate*: si le das varios archivos, los muestra uno tras otro.

## Ejemplo

```
$ cat .r/hola
Si encontraste esto, leíste el manual.
Ya vas mejor que la mayoría.
— R.
```

## En este servidor

- `cat archivo1 archivo2`: varios archivos seguidos.
- `-n`: numera los renglones.

## En tu Linux real

Funciona igual. Para archivos largos conviene un visor como `less` (se sale con `q`) o ver solo una parte con `head` y `tail`.
