# `man`

## Para qué sirve

`man` abre el manual de un comando: qué hace y todas sus opciones.

## Ejemplo

```
$ man ls
```

## En este servidor

Las páginas vienen en español y solo traen las opciones que acepta este servidor.

## En tu Linux real

Casi siempre el manual viene en inglés y trae todas las opciones. Se recorre con las flechas, se busca con `/palabra` y se sale con `q`. Para una ayuda rápida, casi todos los comandos aceptan `--help`. Los comandos internos de bash (`cd`, `history`, `exit`) no tienen página propia: usa `help cd`. Si instalas `manpages-es` y tu sistema está en español, muchas páginas salen en español.
