# `mv`

## Para qué sirve

`mv` mueve o renombra archivos y carpetas.

## Ejemplo

```
$ mv notas.txt notas-octubre.txt
$ mkdir respaldo
$ mv notas-octubre.txt respaldo/
```

## En este servidor

Sin opciones.

## En tu Linux real

Igual, y también reemplaza el destino sin preguntar. `mv -i` pregunta antes. Si escribes `respaldo/` con diagonal, la carpeta tiene que existir.
